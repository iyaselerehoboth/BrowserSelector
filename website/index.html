01 / SET UP

Make it your default.

Install BrowserSelector, open Preferences, and choose Make default. It receives links and passes them to the browser you choose.

02 / CHOOSE

Open a link your way.

Click a destination in the picker, or use the arrow keys and Return. Assign a browser shortcut in Preferences for a quicker handoff.

03 / REMEMBER

Let familiar links flow.

Check Always use my choice before choosing. That website and its subdomains will use your saved browser or profile next time.

Save a website choice or create a regex rule in Preferences → Rules. Change or remove a rule whenever your workflow changes.

Get the app

A public download has not been published yet. If you received a DMG from the maintainer, follow the steps below. Developers can build from source.

View the repository ↗

The source is available on GitHub. See the Releases page for future packages.

Install from a DMG

  1. Open the disk image and drag BrowserSelector into Applications.
  2. Eject the disk image, then open the app from Applications.
  3. In Preferences → General, choose Make default. You can also select it in System Settings → Desktop & Dock → Default web browser.
  4. Open a link from another app to try the picker.

Current sharing builds are ad-hoc signed and not Apple-notarized. If macOS blocks a build you trust, follow Apple’s Open Anyway instructions.

Enable Safari profiles

  1. Create your profiles in Safari → Settings → Profiles.
  2. Enable Safari profile selection in BrowserSelector → Preferences → Browsers.
  3. Allow BrowserSelector in System Settings → Privacy & Security → Accessibility.
  4. Choose Open Safari and refresh. Make sure Safari’s browser row is visible in the picker.

Accessibility allows the app to select Safari’s profile menu and navigate the new window. Full Disk Access is not required. After renaming a Safari profile, select it again in saved rules.

Good to know

A few more details.

Does this replace my browser?

BrowserSelector handles the handoff. Your existing browsers still display websites, manage accounts, and store tabs. You can switch your default browser back in System Settings at any time.

Will it remember every choice?

Only when you check “Always use my choice” before selecting a destination. The option starts unchecked for each new prompt. Edit saved choices in Preferences → Rules.

What happens if I remove a profile?

A missing or unreadable Chromium profile falls back to the browser default. If a selected Safari profile cannot be opened, BrowserSelector displays an error and leaves the link unopened. Update your rule to choose an available profile.

Why do unrelated apps appear in the picker?

macOS may report apps such as download managers as link handlers. Use the eye icon in Preferences → Browsers to hide destinations you don’t need.

How can I report an issue or contribute?

Use the repository’s issue tracker if you have access. Include your macOS version, browser version, expected destination, and what happened. Avoid including private account details or sensitive URLs.
